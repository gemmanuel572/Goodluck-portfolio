# Goodluck Emmanuel — AI Engineering Portfolio

A lightweight, responsive, Liquid Glass-inspired personal portfolio using HTML, CSS, and JavaScript. No npm or build step required.

## Run locally
Open `index.html` in a browser, or from this folder run `python3 -m http.server 8000` and visit `http://localhost:8000`.

## Publish
You can publish this folder using GitHub Pages, Netlify, or another static host. For GitHub Pages, create a public repository, upload these files at the root, and enable GitHub Pages in the repository's Settings → Pages using the `main` branch root.

## Customize
Edit `index.html` to update bio, projects, links and contact information. Update the colors and glass styling in `styles.css`.

The profile card displays initials as a placeholder rather than inventing a photograph. The contact buttons link to public professional profiles and do not collect private information.
